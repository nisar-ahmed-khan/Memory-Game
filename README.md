Memory Card Game

A simple and interactive Memory Card Game built using HTML, CSS, and JavaScript.

The idea is simple: flip the cards, find matching pairs, and try to complete the game in as few moves as possible. I built this project to practice JavaScript and get a better understanding of how interactive web applications work.

🎮 Features

- Interactive card-flipping animations
- Match identical animal cards
- Move counter to track your attempts
- Timer to track your playing time
- Start, stop, and restart game options
- Winning screen after finding all pairs
- Responsive design

🛠️ Technologies Used

- HTML5 – Structure of the game
- CSS3 – Styling, layout and animations
- JavaScript – Game logic and interactivity

📚 What I Practiced

While building this project, I got hands-on experience with:

- DOM Manipulation
- Event Listeners and Event Handling
- Arrays and Array Methods
- Functions and Conditional Statements
- Loops and Logical Operators
- "setTimeout()" and "setInterval()"
- Game State Management
